## 12:27 — jq para filtrar (JSON)

Usé `jq` para sacar solo campos que me importan de un JSON gigante. Indispensable con APIs.

```bash
cat data.json | jq '.[].login'
```

> `jq .` solo ya formatea bonito.

## 12:28 — Variables de entorno (Backend)

Moví secretos a `.env` y los leo con `os.getenv`. Nada de claves quemadas en el código.

## 12:29 — Comprensiones con condición (Python)

Hoy practiqué filtrar listas sin escribir for completo. Más legible cuando la condición es simple, pero si se anida mucho mejor volver al for normal.

```python
pares = [x for x in range(20) if x % 2 == 0]
# equivalente legible a un for + append
```

> `python3 -m py_compile archivo.py` para chequeo rápido de sintaxis.

*Pequeño avance pero constante, que es lo que importa.*
