## 12:06 — Capas y cache de build (Docker)

Entendí por qué el orden del Dockerfile importa: lo que cambia poco va arriba para aprovechar caché. Copiar requirements antes del código.

```dockerfile
COPY requirements.txt .
RUN pip install -r requirements.txt
COPY . .
```

> `docker build --progress=plain` para debuggear builds.

*Pequeño avance pero constante, que es lo que importa.*
