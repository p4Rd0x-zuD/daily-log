## 14:24 — Manejo de archivos con with (Python)

Repasé por qué siempre usar `with open(...)`. Se cierra solo aunque falle algo en el medio y evita leaks en scripts largos.

```python
with open('datos.txt', encoding='utf-8') as f:
    lineas = [l.strip() for l in f if l.strip()]
```

> Tip: especifica siempre `encoding='utf-8'` en Windows/Linux mixto.

*Lo anoto para no olvidarlo en el próximo proyecto.*


## 14:25 — Variables de entorno (Backend)

Moví secretos a `.env` y los leo con `os.getenv`. Nada de claves quemadas en el código.

```python
import os
token = os.getenv('API_TOKEN', '')
```

> Agrega `.env` al `.gitignore` siempre.

*Lo anoto para no olvidarlo en el próximo proyecto.*


## 14:25 — Qué muestra un ping (Redes)

Repasé que `ping` mide latencia y pérdida, no velocidad. Si hay loss alto, ni el mejor código salva la app.

```bash
ping -c 4 8.8.8.8
```

> `-c 4` para no dejarlo infinito.

*Lo anoto para no olvidarlo en el próximo proyecto.*


## 14:25 — Un test mínimo útil (Testing)

Escribí un assert simple antes del código para fijar el comportamiento esperado. No TDD estricto, solo redacción clara.

```python
assert suma(2, 3) == 5
```

> Un test que corre siempre > cinco perfectos que no corres.

*Pequeño avance pero constante, que es lo que importa.*
