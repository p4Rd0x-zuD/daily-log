## 13:12 — GROUP BY + HAVING (SQL)

Practiqué agrupar y filtrar grupos con HAVING (no WHERE). Útil para duplicados y conteos.

```sql
SELECT email, COUNT(*) c
FROM usuarios
GROUP BY email
HAVING COUNT(*) > 1;
```

> Primero agrupa, después filtra el grupo.

*Pequeño avance pero constante, que es lo que importa.*

## 13:14 — Diccionarios con get y setdefault (Python)

Evité varios `if key in dict` usando `.get()` con default y `setdefault` para contadores. El código quedó más corto.

```python
conteo = {}
for w in palabras:
    conteo[w] = conteo.get(w, 0) + 1
```

> Para contadores grandes, `collections.Counter` es aún mejor.
