## 14:24 — JOIN básico (SQL)

Repasé INNER JOIN para cruzar tablas por id. Dibujar las tablas en papel ayuda a no perderse.

```sql
SELECT u.nombre, p.total
FROM usuarios u
JOIN pedidos p ON p.user_id = u.id
LIMIT 10;
```

> Empieza con LIMIT 10 para no traer toda la tabla.

*Esto me va a servir directo en lo que estoy armando.*


## 14:24 — Permisos y chmod (Linux)

Repasé `rwx` y el modo numérico. 755 para carpetas/scripts, 644 para archivos normales. `ls -l` para verificar.

```bash
chmod 755 script.sh
ls -l script.sh
```

> `chmod +x` equivale rápido para hacer ejecutable.

*Me quedó una duda, la dejo para revisar mañana con calma.*


## 14:25 — Fetch con manejo de error (Frontend)

Practiqué `fetch` chequeando `response.ok` antes del `.json()`. Sin eso los 404 pasan como éxito.

```js
const r = await fetch(url);
if (!r.ok) throw new Error(r.status);
const data = await r.json();
```

> Envuelve en try/catch y muestra estado de carga.

*Mañana quiero profundizar con un ejemplo más grande.*
