## 13:07 — JOIN básico (SQL)

Repasé INNER JOIN para cruzar tablas por id. Dibujar las tablas en papel ayuda a no perderse.

```sql
SELECT u.nombre, p.total
FROM usuarios u
JOIN pedidos p ON p.user_id = u.id
LIMIT 10;
```

> Empieza con LIMIT 10 para no traer toda la tabla.

## 13:09 — Rebase vs merge en rama personal (Git)

Practiqué `git pull --rebase` para mantener historial lineal en este repo. Solo lo uso en ramas mías, nunca en ramas compartidas.

```bash
git pull --rebase origin main
git log --oneline -8
```

> `git status` antes de cualquier pull, siempre.

*Lo anoto para no olvidarlo en el próximo proyecto.*
