## 13:08 — Capas y cache de build (Docker)

Entendí por qué el orden del Dockerfile importa: lo que cambia poco va arriba para aprovechar caché. Copiar requirements antes del código.

```dockerfile
COPY requirements.txt .
RUN pip install -r requirements.txt
COPY . .
```

> `docker build --progress=plain` para debuggear builds.

*Lo anoto para no olvidarlo en el próximo proyecto.*


## 13:09 — Sintaxis que siempre olvido (Cron)

Repasé cron: minuto hora día-mes mes día-semana. `*/15 * * * *` cada 15 min. GitHub Actions usa UTC.

```bash
# 13:30 UTC = 08:30 Bogotá
30 13 * * *
```

> Prueba primero con `workflow_dispatch` manual.

*Pequeño avance pero constante, que es lo que importa.*
