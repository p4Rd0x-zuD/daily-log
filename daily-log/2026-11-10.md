## 15:30 — Búsqueda con find y grep (Linux)

Combiné `find` para archivos y `grep -r` para contenido. Mucho más rápido que abrir todo a mano.

```bash
find . -name '*.py' | head
 grep -rn 'TODO' --include='*.py' .
```

> Con `rg` (ripgrep) es aún más rápido si está instalado.

## 15:31 — Qué muestra un ping (Redes)

Repasé que `ping` mide latencia y pérdida, no velocidad. Si hay loss alto, ni el mejor código salva la app.

```bash
ping -c 4 8.8.8.8
```

> `-c 4` para no dejarlo infinito.

## 15:31 — Commits atómicos pequeños (Git)

Me propuse commits de un solo tema con mensaje claro tipo `docs: ...`. Revisar con `git diff --cached` antes de commitear ayuda mucho.

```bash
git add -p
git diff --cached
```

> `git add -p` para agregar por pedazos, no todo de una.

*Lo anoto para no olvidarlo en el próximo proyecto.*
