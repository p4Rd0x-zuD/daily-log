## 17:09 — jq para filtrar (JSON)

Usé `jq` para sacar solo campos que me importan de un JSON gigante. Indispensable con APIs.

```bash
cat data.json | jq '.[].login'
```

## 17:10 — GROUP BY + HAVING (SQL)

Practiqué agrupar y filtrar grupos con HAVING (no WHERE). Útil para duplicados y conteos.

```sql
SELECT email, COUNT(*) c
FROM usuarios
GROUP BY email
HAVING COUNT(*) > 1;
```

> Primero agrupa, después filtra el grupo.
