## 13:05 — Rebase vs merge en rama personal (Git)

Practiqué `git pull --rebase` para mantener historial lineal en este repo. Solo lo uso en ramas mías, nunca en ramas compartidas.

```bash
git pull --rebase origin main
git log --oneline -8
```

> `git status` antes de cualquier pull, siempre.

*Me quedó una duda, la dejo para revisar mañana con calma.*


## 13:06 — Comprensiones con condición (Python)

Hoy practiqué filtrar listas sin escribir for completo. Más legible cuando la condición es simple, pero si se anida mucho mejor volver al for normal.

```python
pares = [x for x in range(20) if x % 2 == 0]
# equivalente legible a un for + append
```
