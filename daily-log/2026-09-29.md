## 14:45 — Rebase vs merge en rama personal (Git)

Practiqué `git pull --rebase` para mantener historial lineal en este repo. Solo lo uso en ramas mías, nunca en ramas compartidas.

```bash
git pull --rebase origin main
git log --oneline -8
```

> `git status` antes de cualquier pull, siempre.

## 14:45 — Manejo de archivos con with (Python)

Repasé por qué siempre usar `with open(...)`. Se cierra solo aunque falle algo en el medio y evita leaks en scripts largos.

```python
with open('datos.txt', encoding='utf-8') as f:
    lineas = [l.strip() for l in f if l.strip()]
```

> Tip: especifica siempre `encoding='utf-8'` en Windows/Linux mixto.

## 14:46 — JOIN básico (SQL)

Repasé INNER JOIN para cruzar tablas por id. Dibujar las tablas en papel ayuda a no perderse.

```sql
SELECT u.nombre, p.total
FROM usuarios u
JOIN pedidos p ON p.user_id = u.id
LIMIT 10;
```

> Empieza con LIMIT 10 para no traer toda la tabla.
