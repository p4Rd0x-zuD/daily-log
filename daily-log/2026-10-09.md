## 13:52 — Fetch con manejo de error (Frontend)

Practiqué `fetch` chequeando `response.ok` antes del `.json()`. Sin eso los 404 pasan como éxito.

```js
const r = await fetch(url);
if (!r.ok) throw new Error(r.status);
const data = await r.json();
```

> Envuelve en try/catch y muestra estado de carga.

## 13:53 — Diccionarios con get y setdefault (Python)

Evité varios `if key in dict` usando `.get()` con default y `setdefault` para contadores. El código quedó más corto.

```python
conteo = {}
for w in palabras:
    conteo[w] = conteo.get(w, 0) + 1
```

> Para contadores grandes, `collections.Counter` es aún mejor.

## 13:54 — Búsqueda con find y grep (Linux)

Combiné `find` para archivos y `grep -r` para contenido. Mucho más rápido que abrir todo a mano.

```bash
find . -name '*.py' | head
 grep -rn 'TODO' --include='*.py' .
```

> Con `rg` (ripgrep) es aún más rápido si está instalado.

## 13:55 — Cache de pip (GitHub Actions)

Vi que cachear dependencias baja el tiempo de 2min a 30s. Pequeño cambio, gran ahorro diario.

```yaml
- uses: actions/setup-python@v5
  with:
    python-version: '3.11'
    cache: 'pip'
```

> El log de Actions muestra si hubo cache hit.
