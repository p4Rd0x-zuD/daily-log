## 13:03 — GROUP BY + HAVING (SQL)

Practiqué agrupar y filtrar grupos con HAVING (no WHERE). Útil para duplicados y conteos.

```sql
SELECT email, COUNT(*) c
FROM usuarios
GROUP BY email
HAVING COUNT(*) > 1;
```

> Primero agrupa, después filtra el grupo.

## 13:04 — Capas y cache de build (Docker)

Entendí por qué el orden del Dockerfile importa: lo que cambia poco va arriba para aprovechar caché. Copiar requirements antes del código.

```dockerfile
COPY requirements.txt .
RUN pip install -r requirements.txt
COPY . .
```

> `docker build --progress=plain` para debuggear builds.

*Lo anoto para no olvidarlo en el próximo proyecto.*
