## 13:29 — Permisos y chmod (Linux)

Repasé `rwx` y el modo numérico. 755 para carpetas/scripts, 644 para archivos normales. `ls -l` para verificar.

```bash
chmod 755 script.sh
ls -l script.sh
```

> `chmod +x` equivale rápido para hacer ejecutable.
