## 13:29 — Permisos y chmod (Linux)

Repasé `rwx` y el modo numérico. 755 para carpetas/scripts, 644 para archivos normales. `ls -l` para verificar.

```bash
chmod 755 script.sh
ls -l script.sh
```

> `chmod +x` equivale rápido para hacer ejecutable.

## 13:29 — Un test mínimo útil (Testing)

Escribí un assert simple antes del código para fijar el comportamiento esperado. No TDD estricto, solo redacción clara.

```python
assert suma(2, 3) == 5
```

> Un test que corre siempre > cinco perfectos que no corres.
