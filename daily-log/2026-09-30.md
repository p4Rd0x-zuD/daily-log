## 13:29 — Permisos y chmod (Linux)

Repasé `rwx` y el modo numérico. 755 para carpetas/scripts, 644 para archivos normales. `ls -l` para verificar.

```bash
chmod 755 script.sh
ls -l script.sh
```

> `chmod +x` equivale rápido para hacer ejecutable.

## 13:29 — Un test mínimo útil (Testing)

Escribí un assert simple antes del código para fijar el comportamiento esperado. No TDD estricto, solo redacción clara.

```python

```

## 13:30 — Rebase vs merge en rama personal (Git)

Practiqué `git pull --rebase` para mantener historial lineal en este repo. Solo lo uso en ramas mías, nunca en ramas compartidas.

```bash
git pull --rebase origin main
git log --oneline -8
```

> `git status` antes de cualquier pull, siempre.

*Lo anoto para no olvidarlo en el próximo proyecto.*
