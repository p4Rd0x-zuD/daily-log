## 17:23 — Commits atómicos pequeños (Git)

Me propuse commits de un solo tema con mensaje claro tipo `docs: ...`. Revisar con `git diff --cached` antes de commitear ayuda mucho.

```bash
git add -p
git diff --cached
```

> `git add -p` para agregar por pedazos, no todo de una.

## 17:24 — Manejo de archivos con with (Python)

Repasé por qué siempre usar `with open(...)`. Se cierra solo aunque falle algo en el medio y evita leaks en scripts largos.

```python
with open('datos.txt', encoding='utf-8') as f:
    lineas = [l.strip() for l in f if l.strip()]
```

> Tip: especifica siempre `encoding='utf-8'` en Windows/Linux mixto.
