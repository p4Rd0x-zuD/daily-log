## 17:23 — Commits atómicos pequeños (Git)

Me propuse commits de un solo tema con mensaje claro tipo `docs: ...`. Revisar con `git diff --cached` antes de commitear ayuda mucho.

```bash
git add -p
git diff --cached
```

> `git add -p` para agregar por pedazos, no todo de una.
