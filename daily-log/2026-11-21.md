## 15:10 — Fetch con manejo de error (Frontend)

Practiqué `fetch` chequeando `response.ok` antes del `.json()`. Sin eso los 404 pasan como éxito.

```js
const r = await fetch(url);
if (!r.ok) throw new Error(r.status);
const data = await r.json();
```
