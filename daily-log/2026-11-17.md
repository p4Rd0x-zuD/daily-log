## 16:50 — Capas y cache de build (Docker)

Entendí por qué el orden del Dockerfile importa: lo que cambia poco va arriba para aprovechar caché. Copiar requirements antes del código.

```dockerfile
COPY requirements.txt .
RUN pip install -r requirements.txt
COPY . .
```

> `docker build --progress=plain` para debuggear builds.

*Lo anoto para no olvidarlo en el próximo proyecto.*

## 16:51 — Commits atómicos pequeños (Git)

Me propuse commits de un solo tema con mensaje claro tipo `docs: ...`. Revisar con `git diff --cached` antes de commitear ayuda mucho.

```bash
git add -p
git diff --cached
```

> `git add -p` para agregar por pedazos, no todo de una.
