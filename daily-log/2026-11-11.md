## 15:15 — No subir secretos (Seguridad)

Revisé `git log -p` para verificar que nunca subí un token. `gh secret` y `.gitignore` bien puestos.

```bash
git log -p --all -S 'API_TOKEN' -- activity.log
```

> Si se filtra, rota la clave de una, no solo la borres.

## 15:16 — Historial y atajos (Terminal)

Practiqué `Ctrl+R` para buscar comandos viejos y `!!` para repetir el último con sudo. Ahorra mucho tiempo.

```bash
sudo !!
# repite último comando con sudo
```

> `history | grep git` para encontrar ese comando perdido.
