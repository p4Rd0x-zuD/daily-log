## 16:28 — Fetch con manejo de error (Frontend)

Practiqué `fetch` chequeando `response.ok` antes del `.json()`. Sin eso los 404 pasan como éxito.

```js
const r = await fetch(url);
if (!r.ok) throw new Error(r.status);
const data = await r.json();
```

> Envuelve en try/catch y muestra estado de carga.

*Lo anoto para no olvidarlo en el próximo proyecto.*


## 16:29 — Capas y cache de build (Docker)

Entendí por qué el orden del Dockerfile importa: lo que cambia poco va arriba para aprovechar caché. Copiar requirements antes del código.

```dockerfile
COPY requirements.txt .
RUN pip install -r requirements.txt
COPY . .
```

> `docker build --progress=plain` para debuggear builds.
