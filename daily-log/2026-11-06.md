## 14:59 — GROUP BY + HAVING (SQL)

Practiqué agrupar y filtrar grupos con HAVING (no WHERE). Útil para duplicados y conteos.

```sql
SELECT email, COUNT(*) c
FROM usuarios
GROUP BY email
HAVING COUNT(*) > 1;
```

> Primero agrupa, después filtra el grupo.

*Lo anoto para no olvidarlo en el próximo proyecto.*


## 14:59 — Commits atómicos pequeños (Git)

Me propuse commits de un solo tema con mensaje claro tipo `docs: ...`. Revisar con `git diff --cached` antes de commitear ayuda mucho.

```bash
git add -p
git diff --cached
```

> `git add -p` para agregar por pedazos, no todo de una.
