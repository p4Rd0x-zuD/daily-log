## 13:56 — Diccionarios con get y setdefault (Python)

Evité varios `if key in dict` usando `.get()` con default y `setdefault` para contadores. El código quedó más corto.

```python
conteo = {}
for w in palabras:
    conteo[w] = conteo.get(w, 0) + 1
```

> Para contadores grandes, `collections.Counter` es aún mejor.

## 13:57 — Rebase vs merge en rama personal (Git)

Practiqué `git pull --rebase` para mantener historial lineal en este repo. Solo lo uso en ramas mías, nunca en ramas compartidas.

```bash
git pull --rebase origin main
git log --oneline -8
```

> `git status` antes de cualquier pull, siempre.
